受控O3展开在第一阶段周期最少，但O2+LTO体积更小、IPC较高。EVOLVE2先使用O2+LTO作为同固件硬件对照；不能把不同二进制的退休数变化当作硬件IPC收益。

新GCC已独立安装并校验官方SHA-256，未改系统PATH。链接段对齐空隙改为RV32I NOP填充；memcpy/memset增加used/externally_visible以保留LTO运行库入口。官方算法源码校验保持通过。早期padding/LTO失败在reports/compiler_initial，ROM超限候选未扩容ROM来绕过。

原始UART、独立timer采样、bus/dual/evolve指标均在reports/compiler/<配置>/run2或run8。未完成PGO；尚未认定必须使用PGO。
