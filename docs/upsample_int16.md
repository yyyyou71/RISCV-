# INT16 2倍最近邻上采样

日期：2026-10-27。状态：DDR搬运、CPU任务表与五类算子混合网络仿真通过；完整检测网络及综合上板待完成。

## 1. 做什么

逐通道复制像素，将H×W×C变为2H×2W×C：

```text
输入：a b        输出：a a b b
      c d              a a b b
                       c c d d
                       c c d d
```

对应参考C函数`upsample2x`：`out[y,x,c]=in[y/2,x/2,c]`，这里的除法取整数商。
逐位保留INT16，包括-32768；不做插值乘法、量化、ReLU或饱和，尺度不变。

## 2. DDR与片上数据流

输入、输出仍为HWC-align16(C)，每元素2字节：

```text
输入大小 = H × W × align16(C) × 2
输出大小 = 输入大小 × 4
```

RTL在`vsrc/conv2d_ddr_engine.v`，复用现有DDR客户端和块搬运，不增加外部端口。

1. 遍历输入像素及每组8个通道，读取一个16字节源字。
2. 将有效通道保存在128位寄存器中，尾部填充清零。
3. 依次写入对应输出2×2区域的左上、右上、左下、右下。
4. 四笔DDR写入都完成后，才处理下一组通道或输入像素。

一个源字只读一次、用于四笔写入。完全属于填充的通道组直接写四个零字，不读取DDR。
写回地址支持按上述顺序跳转，不要求全图按地址递增写入；横向和换行地址使用加法推进。
片上只增加源字缓存、计数和地址寄存器，没有整图/整行缓存或新增RAM IP，卷积MAC规模不变。
DDR客户端仍只允许一笔块请求在途；未实现双缓冲、读写重叠或层间融合。
实际资源和时序仍须用PDS综合确认。

CPU提交地址和尺寸，完成状态沿用已有CDC邮箱返回；CPU只调度，不复制上采样数据。

## 3. MMIO与任务ABI

| 寄存器 | Upsample2x含义 |
| --- | --- |
| AI_OPCODE（0x30248） | 5 |
| AI_INPUT（0x30208） | 输入DDR字节地址 |
| AI_OUTPUT（0x30214） | 输出DDR字节地址 |
| AI_HW（0x30218） | 输入H/W，低16位H、高16位W |
| AI_CHANNELS（0x3021c） | 低16位Cin、高16位Cout，须相等 |
| AI_POST（0x30238） | 4，INT16格式，不执行Q13量化 |
| AI_WEIGHT、AI_BIAS、AI_QUANT、AI_GROUP、AI_CONV | 均为0 |

仅支持`AI_ACT_WIDTH=16`和AIM1版本2。
输入H/W为1..32767，C为1..65535；倍增后的尺寸仍可放入下一条任务的16位H/W字段。
所有地址16字节对齐；按完整输入和四倍输出大小做64位范围及重叠检查，禁止原地/部分重叠操作。
输入输出均须在512MiB内，CPU任务输出还必须在模型工作区。
DONE等四次复制及整层最后一笔DDR写入完成后才置位；`mac_issues=0`，`cycles`正常统计。
错误码和原生FAULT锁定/共同复位规则沿用既有引擎。

64字节任务的opcode为5，out_h=2H、out_w=2W；未使用的字段与保留字须清零。
CPU和打包器共同检查形状，DDR原生读写由硬件完成。

```json
{"name":"up","op":"upsample2x","input":"previous_layer"}
```

只接受name/op/input，不接受scale、mode、量化或卷积字段；该操作码固定为2倍最近邻。
下一层可直接读取`up`，也可以将其与相同输出高宽的另一张图Concat。

Python只布局、打包和启动仿真，不新增独立网络数学实现。

- 16种独立DDR配置，包含1/5/8/9/15/16/17/31/32/33/144/288/384/672通道、单点/行/列、矩形及多行换行。
- 随机INT16与-32768/32767锚点、非零输入填充和输出毒值；逐次写入、最终结果、输出形状和零MAC计数检查。
- 检查同一输出字只写一次、读命令数等于有效输入字数，证明四次复制复用同一源字；读取不得越过输入区域。
- 地址0、输入/输出恰好结束于512MiB上界、跨2KiB边界、只读数据和哨兵保护。
- 25种非法配置在DDR操作前拒绝，特别覆盖倍增尺寸溢出、四倍输出范围，以及仅在扩张输出尾部发生的重叠。
- 读等待中复位、四次复制进行到一半时复位、读地址/写地址超时锁定及共同复位重放。
- DDR正常、随机停顿、零读写延迟三组均通过，每组检查1256个最终输出字，包含4次完整重放；另有复制中途复位的部分写入。
- CPU一次处理28份模型请求、14次AI提交，比较18252个DDR字；24种错误、错误后继续运行、不复位重跑通过。
- 三种有效网络：卷积→池化→上采样→ADD→Concat→卷积；上采样→真实`model.13.cv1`两尺度卷积（group_split=384）；连续两次上采样。
- 全部中间输出、只读资产、哨兵、报告和性能计数均检查，CPU仅写运行报告；原生FAULT停止和8位硬件拒绝16位包通过。
- 打包器验证输入/输出尺寸上界，32767输入高对应65534输出高；8/16位引擎及16位外设总线严格lint通过。
