## P1 数值约定

依据 `origin/main@9bd2479:pc_ai/verify_trident.py:prepare_image`：RGB 顺序，
输出区间为 `floor(i*input/96)..ceil((i+1)*input/96)-1`，均值舍入到最近整数、正好一半取偶数。
这与目前模型移植约定一致，不改成 letterbox、最近邻或旧演示中的近似抽取。

1080p 固定模式下，每个输出像素覆盖 20×12=240 个输入像素；纵向边界为
`[0,12), [11,23), [22,34), [33,45), [45,57), ...`，部分边界行必须同时参与两个输出行。
采用 96 组 RGB 累加值，使用紫光 Simple Dual Port RAM；无需在片上保存整幅 1080p 图像。

输出为小端 INT16，HWC、16 通道，每像素 32 bytes：R、G、B 后补 13 个零。
每像素输出两个 128-bit 拍。一帧 18,432 拍、294,912 bytes。
输入不可背压；下游长期不接收、尺寸异常、超时或取消时使整帧无效。
已经流出的部分数据必须由 P2 的事务管理丢弃，只有终态 DONE 且 ERROR=0 才能发布给 AI。

P1 独立核的验证报告仍保留其独立范围；P2 的实际 HDMI/DDR 接线和统一帧槽归属见 `hdmi_tensor_p2.md`。
当前 CPU IP 已切换并重新生成为 `firmware/video_diagnostic/` 视频+首层AI+整网服务+画框发送+纯SPI镜像；
需重新生成位流后才能在板上运行。原 CoreMark hex 保留。
